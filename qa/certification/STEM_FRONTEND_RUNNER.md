# STEM-04: ejecutor frontend v1

El mismo script `scripts/certification/frontend-runner.sh` y sus pruebas se mantienen en Lite y Plus. Ejecuta exclusivamente `npm ci`, `npm run typecheck`, `npm test`, `npm run build`; registra SHA de checkout, versiones y hash del lockfile. No cambia entorno, comandos, artefactos, permisos, timeouts ni nombres de pasos. Los tests de la envoltura simulan herramientas y verifican argumentos, dos layouts, fallos y rechazo de directorios o fases inválidas. El acumulativo ejecuta estas regresiones con unittest; la CI sigue comprobando el producto. No omite pasos, no transfiere PASS y no afirma ahorro de runner. STEM-05 deberá probar equivalencia efectiva y reutilización verificable. La revisión de equivalencia preservará diferencias de configuración observadas en STEM-03.
